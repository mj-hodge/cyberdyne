Gate Behavior (Phase 3)

The single hard gate fires after Design. The agent stops and presents:

  • Requirements summary — distilled from Seed and Discovery
  • Design plan — architecture, components, key decisions
  • Epics and stories — full list with acceptance criteria

On approval, the agent creates the Asana structure and sends a Slack notification before continuing to Phase 4.

Slack Notifications

After each non-gate phase transition, the agent sends a Slack notification to the webhook configured in config.yaml, waits 90 seconds, then continues automatically.

*Phase {N} Complete: {Phase Name}*
Project: {project name}
Produced: {one-line summary}
Next: Phase {N+1} ({name}) starting in 90s
Asana: {project URL}

Model Policy

All phases default to claude-sonnet-4-6. To change the model for any phase, edit config.yaml:

models:
  default: claude-sonnet-4-6
  phases:
    phase-1: claude-sonnet-4-6   # change this line to override
    phase-3: claude-opus-4-8     # e.g. use Opus for Design only

Agents MUST read this config at startup. No autonomous model selection is permitted.

Asana Integration

  • You create the project in Asana and write requirements in the project description.
  • Phase 1 reads the project description as its requirements input.
  • After Phase 3 gate approval, the agent creates:
    • Epics → Asana sections within the project
    • Stories → Asana tasks grouped under each section, with acceptance criteria
